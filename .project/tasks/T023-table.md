# T023 — Ship table with its cell, head, and numeric directives and the table compositions of earlier items

## Context

`table` (docs/specs/specs/table.md; `YetiTable`, `YetiTableCell` on `th`, `td`, and `tr`, `YetiTableHead` on `thead` with `sticky`, the any-element marker `YetiNumeric`, the package type `YetiTableAlign`) styles native tables. Its stories compose icon (T021), visually-hidden (T011), and scroller (T017); earlier items compose it (`cluster--legend`'s `yetiNumeric`, `scroller--wide-table`, `container--table-column`), so this task adds those. `border`, `align`, and `nowrap` are removed-kind (T003; decision 196 ties `nowrap` to decision 9). The negative-control route without a `tbody` (table.md:411) records its hydration error and is exempt from the no-mismatch and axe checks (INTENT SC3). SC3 also places table's pinned-head Shift+Tab walk (table.md:416, A11Y-22's table repeat) on the Fixture route (INTENT Corrections, 2026-10-10). Forced-colours borders that vanish bring a row and a rule (table.md:429; INTENT E7).
