# T011 — Ship enter and visually-hidden with enter's held-bundle and preload cases

## Context

`enter` (docs/specs/specs/enter.md; class `NgxYetiEnter`, an ADR 0080 rename, selector `yetiEnter`) plays Yeti's arrival animations, with a `once` form withheld until the element is scrolled to; `visually-hidden` (docs/specs/specs/visually-hidden.md; `YetiVisuallyHidden`) hides text from sight but not from the accessibility tree. Both compose into later items (cluster's shared host with enter; scroller's and table's hidden labels). enter.md:272 asks for its client insertion cases with and without the preload list, which one build cannot do; T002 settled it by a Departures row (INTENT E15): without the preload on the Fixture app, with it on the story `enter--inserted-preloaded`.
