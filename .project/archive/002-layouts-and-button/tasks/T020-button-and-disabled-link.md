# T020 — Ship button and YetiButtonDisabledLink with A11Y-1a, event replay, and the NG8002 check

## Context

`button` (docs/specs/specs/button.md; `YetiButton` on `button`, `a`, `input`, and `label`, and `YetiButtonDisabledLink` on `a[yetiButton][disabled]`) is the control most later items compose. It owns ledger row A11Y-1a, the first item rule of the package accessibility stylesheet (ngx-yeti/ngx-yeti-globals.css): under forced colours a pressed toggle and a checked `label.button` look like their siblings, so one rule in `@layer ngx-yeti` on `.button[aria-pressed="true"]` and `.button:has(> input:checked)` draws them (ledger.md:25; SC6). It proves event replay on a toggle (SC7, button.md:352) and acquires `spinner` with `button` (ticket 50 decision 109), so the spinner cases that need a button land here. INTENT Constraints: the ledger row outranks the architecture guide's "Avoided: a package rule selecting `.button`" (architecture-guide.md:287); the NG8002 when `YetiButtonDisabledLink` is not imported (button.md:179) gets a compile-time check. This task also delivers the Storybook stories surface of the Surface contract.
