### Open

Each point is marked "(open: see ticket)" in the spec. Impact and confidence follow the trap-quadrant rule (map, Standing rulings, 2026-10-03). No point has HIGH impact, so none is in the trap quadrant.

1. **Which `aria-current` form the examples lead with, and whether `RouterLinkActive`'s attribute is in the server HTML** (spec sections 4 usage rule 4, 8, and 10; layer 3). Impact: MEDIUM. Confidence: MEDIUM. Building-blocks 1.10 allows both writers, the consumer and `RouterLinkActive` with `ariaCurrentWhenActive="page"`, and names neither as the default. `RouterLinkActive` writes the attribute through `Renderer2` in a `queueMicrotask` after the Router has navigated (`NGP/router/src/directives/router_link_active.ts:228-249`, read). That it runs before the server serializes the page is inferred, not measured. If it does not, a form (b) trail has no current step in the server HTML, which breaks the JavaScript-off guarantee for that form. **Recommendation:** lead with form (a), the consumer's binding on the last step from the trail's data (`[attr.aria-current]="$last ? 'page' : null"`), because a trail derived from the route has its current step last by construction, and the binding is a plain template binding that is equal on the server and the client. Document form (b) for trails whose every step is a link, with exact matching (usage rule 5). Keep the layer-3 assertion for form (b). If it fails, add a usage rule that form (b) is for client-rendered trails only, and remove form (b) from the JavaScript-off e2e case. Decided 2026-10-03 in ticket 50, decision 87 (orchestrator, full AFK mode).
2. **Forced colours and the current step** (spec section 7; layer 4; Out of Scope). Impact: LOW, because forced colours is not an AA criterion of its own (ticket 17 section 2.6) and screen-reader users keep the state. Confidence: MEDIUM. Ticket 17 did not measure the breadcrumbs page under forced colours. The current step differs from the links by its strong weight, which forced colours does not override, as the toc's bold current link showed (ticket 17 section 2.6, measured); the pagination's current link, drawn by colour, was lost. **Recommendation:** no ledger row and no package CSS now; the layer-4 case asserts that the computed weight difference survives `forcedColors: 'active'` in Chromium and Firefox and records a screenshot. If it fails, add a ledger row owned by `breadcrumbs` after A11Y-1f's shape, with one rule in `@layer ngx-yeti` on `.breadcrumbs [aria-current="page"]`. This follows [ticket 50](50-decide-open-points-of-the-specs.md) decision 26 (measure, no rule until a gap is found). Decided 2026-10-03 in ticket 50, decision 88 (orchestrator, full AFK mode).
3. **No contrast assertion for the separator** (spec section 7, 1.4.3 row). Impact: LOW. Confidence: MEDIUM. axe does not check generated content, so ADR 0015 point 3 would ask the play function for anything axe misses. This spec reads the separator as decoration: it has empty alternative text by design, and the trail's structure is carried by the landmark and the list (the APG example's reasoning), so WCAG 1.4.3's "pure decoration" exception applies and 1.4.11 does not (the separator is not needed to understand the content). **Recommendation:** no assertion. If the orchestrator reads the separator as content, the `breadcrumbs--default` play function asserts at least 3:1 (1.4.11) between the separator's computed colour and the surface in both schemes, with [ticket 50](50-decide-open-points-of-the-specs.md) decision 8's formula. Decided 2026-10-03 in ticket 50, decision 89 (orchestrator, full AFK mode).
4. **A `routerLink` step inside a `hydrate never` block** (spec sections 4 usage rule 10 and 10; layer 4). Impact: MEDIUM: a step that does nothing on click fails WCAG 2.1.1 for that trail. Confidence: LOW. `RouterLink` declares a `click` listener on its `a`, so the server HTML carries `jsaction`, and Angular's dispatcher cancels the native navigation of an `<a>` with `jsaction` when it dispatches (ADR 0011 clause 3; `dispatcher.ts:127-140`, read). Whether events in a `hydrate never` block are captured and held, or left to the browser, was not read or measured. **Recommendation:** keep usage rule 10 (a route-driven trail belongs in content that hydrates), and have layer 4 record what a click does. If the click is held and never replayed, extend usage rule 10: a trail inside `hydrate never` uses plain `href` links without `routerLink`, which navigate as full document loads. The package changes nothing either way, because the listener is the Router's. Decided 2026-10-03 in ticket 50, decision 90 (orchestrator, full AFK mode).

## Answer

Resolved 2026-10-03 by Claude Opus 5.5. Spec: [specs/breadcrumbs.md](../specs/breadcrumbs.md).

One directive in `ngx-yeti/breadcrumbs`: the item directive `YetiBreadcrumbs` on `nav[yetiBreadcrumbs]` (`exportAs: 'yetiBreadcrumbs'`) binds the static class `breadcrumbs` and the presence attribute `data-ngx-yeti-item-breadcrumbs` ([ADR 0045](../adr/0045-each-item-marks-its-host-with-its-own-attribute.md)), binds `data-size` from `size: YetiSizeControl` (`inert` on a `nav`; ticket 26 row 93), and acquires the item file. It is types only, with no part directives, no token, no Aria, and no CDK; Yeti has no module for the item. The name, `role="list"`, and `aria-current="page"` stay the consumer's, and `aria-current` has one writer per element: the consumer's binding from the trail's data, or `RouterLinkActive` with `ariaCurrentWhenActive="page"` and exact matching, which the spec makes a usage rule after reading `RouterLinkActive`'s subset default and its removal of a second writer's value. The separators stay Yeti's generated content with empty alternative text, set only through `--yeti-breadcrumbs-separator`. `YetiBreadcrumbs` is not among the 46 names `yeti.d.ts` exports, so it takes `Yeti`.

Counts: 51 user stories, 11 usage rules, 6 story ids, 4 open points (none with HIGH impact, so none in the trap quadrant). No open point blocks the spec: each has a recommendation the spec already carries. The spec adds no ledger row or upstream-bug row; open point 2 adds a ledger row only if its layer-4 measurement fails.
