# Accessibility and parity ledger

Every standards, accessibility, and Angular Aria, CDK, or Material parity feature the package adds that Yeti itself does not provide, and every accessibility gap found in Yeti, whether or not the package closes it. The user asked for it on 2026-10-01 (map, Standing rulings, items 36 and 44), and, about the forced-colours gap, wrote, verbatim: "Track in accessibility ledger."

The format below is final, set by [Decide: the building-blocks map for every ngx-yeti item](issues/25-decide-building-blocks-map.md) on 2026-10-02. Every spec adds its rows under its own owner, and a spec that closes, changes, or refuses a row updates the row's **Package** column and says so in its decision log. Upstream bugs that are not accessibility issues go in [upstream-bugs.md](upstream-bugs.md). Filing any row upstream is an outward-facing action under the user's identity and needs the user's confirmation first (map, AFK override).

Columns:

- **ID:** `A11Y-<n>`, with a letter suffix where one finding splits into rows with different owners (`A11Y-1a`). An ID is never reused.
- **Item:** the Yeti item, or the shared-utility spec for a feature no item owns.
- **Gap or feature:** what Yeti lacks, or what the package adds.
- **Source:** the standard, criterion, or pattern: WHATWG, WAI-ARIA, a WCAG 2.2 criterion, an APG pattern, or Angular Aria, CDK, or Material parity.
- **What Yeti does:** Yeti's own behaviour at the pin, with the file where it is stated.
- **What the package adds:** the directive, binding, listener, or rule, as decided by the building-blocks map (Part 2 row) and confirmed or changed by the owning spec; "none" where the gap is accepted, with the reason.
- **Building block:** the Aria, CDK, Material, or platform piece it is built on, with `file:line` where one is cited.
- **Verified:** *measured* (reproduced in a browser), *read* (found in source or docs), or *inferred*.
- **Minimal reproduction:** a standalone example showing only the gap; none yet for any row.
- **Tested by:** the test layer of [building-blocks.md](building-blocks.md) 1.12 that asserts the package's behaviour (L1 story play function, L2 browser-level, L3 node-level and SSR smoke, L4 Playwright e2e).
- **Owner:** the spec that owns the row. No row is unowned.
